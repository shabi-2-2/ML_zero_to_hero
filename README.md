# ML_zero_to_hero

Small, runnable Google Colab lessons inspired by Andrej Karpathy's
machine-learning-from-scratch course.

## Lessons

- [Gradient descent from scratch](notebooks/01_gradient_descent_from_scratch.ipynb)

in Google Colab or run locally with Jupyter:

```bash
jupyter notebook notebooks/01_gradient_descent_from_scratch.ipynb
```
